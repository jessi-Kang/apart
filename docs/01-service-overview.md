# 01. 서비스 개요

## 1. 콘셉트

**한 줄 콘셉트**: "이거 진짜 있는 아파트야, AI가 지어낸 거야?" 실존 단지명과 AI가 지은 이름을 가려내는 감별 게임.

본편은 **무한 모드**다. 창구에 들어가면 곧장 세션이 시작되고, 맞히는 만큼 연속이 쌓이고 틀리면 끊긴다. 하루 10문제 데일리는 **제N호 공식전**이라는 선택 참가 랭킹전으로 남아 있다(같은 문제로 전국과 겨루고 싶은 사람만 신청).

한국 아파트 작명 문화(브랜드 + 입지 키워드 + 영어 펫네임의 무한 조합)는 이미 그 자체로 밈이다. "시어머니가 못 찾아오게 이름을 어렵게 짓는다"는 농담이 통용될 만큼 대중적 공감대가 있다. 이 서비스는 그 공감대를 **판별 게임**으로 바꾼다. 실존 단지명과 AI가 지어낸 가짜 단지명을 구분하는 순간, 유저는 자기가 얼마나 '부동산 감각'이 있는지 테스트받는 재미와, 실제 작명이 얼마나 기괴한지 재발견하는 웃음을 동시에 얻는다.

## 2. 네이밍

가칭 **아파트 감별사**를 기본으로 하되, 출시 전 아래 대안과 함께 최종 결정한다.

| 후보 | 방향 | 비고 |
|---|---|---|
| **아파트 감별사** (가칭) | 직관적, 등급명("~감별사")과 연결 | 검색 시 감정평가 관련 결과와 섞일 수 있음 |
| **진짜 아파트** | 게임의 질문 자체를 서비스명으로 | 도메인 확보 쉬움, 밈화 용이("진짜 아파트 몇 점?") |
| **저세상 단지명** | 밈 감성 강조 | 톤이 가벼워 지역 커뮤니티 확장 시 부담 가능 |

결정 기준: (1) 공유 카드에 박았을 때 한눈에 게임이 설명되는가, (2) .kr/.com 도메인 확보 가능한가, (3) 등급명 세계관과 어울리는가.

## 3. 타겟 유저

- **1차 (론칭 타깃)**: 20~40대, 부동산 커뮤니티(부동산 스터디 카페, 네이버 카페)·스레드·X에서 부동산 밈을 소비하는 유저. 청약·전세 경험이 있어 단지명에 대한 감이 있고, "나 이런 거 잘 맞힘"을 인증하고 싶어 한다.
- **2차 (확장 타깃)**: 지역 커뮤니티(당근, 맘카페) 유저. "우리 동네 모드"로 유입. 부동산 지식보다 동네 지리 지식으로 플레이한다.
- **비타깃이지만 유입되는 층**: 아파트에 관심 없는 유저도 이름의 기괴함 자체가 웃겨서 1회성 플레이 가능. 이 층은 리텐션 대상이 아니라 확산(공유) 매개로 본다.

## 4. 핵심 가치 제안

| 유저가 얻는 것 | 설계 장치 |
|---|---|
| "나 몇 점인지" 확인하는 자기 테스트 재미 | 모드별 등급 도장 + 누적 감별사 레벨 |
| 한 판 더 하게 만드는 장력 | 무한 세션의 연속·콤보, 판이 끝나면 나오는 최근 7일 백분위 |
| 자랑/인증 소재 | 접수증 공유 이미지(판정 타일 + 등급 도장 + 관인) |
| 매일 오는 가벼운 습관 | 제N호 공식전(하루 1회, 전원 동일 문제)과 연속 출전 |
| 논쟁 유발 소재 | "이게 진짜라고?" 정답 공개 시 실제 위치·준공년도·세대수 노출 |
| 손을 쓰는 재미 | 이름 조립(조각 퍼즐 + 초성 힌트 + 속도 점수) |

## 5. 참고 사례와 차별점

| 사례 | 배울 점 | 우리와 다른 점 |
|---|---|---|
| **Wordle** | 하루 1회 + 전원 동일 문제 + 이모지 그리드 공유 = 인증 문화 | Wordle은 문제 생성이 단순(단어 사전)해서 카피가 쉬웠음 |
| **꼬맨틀 (한국어 Semantle)** | 한국어 로컬라이징 데일리 게임의 커뮤니티 화력 검증 | 지식 게임이라 진입장벽 있음. 우리 본편은 2지선다라 진입장벽 0 |
| **메트로 타이핑류 (카피에 당한 사례)** | 일회성 콘텐츠는 UI 카피만으로 복제됨 | 우리는 매일 갱신되는 출제 운영 + 가짜 이름 생성 노하우가 핵심이라 UI 카피로는 복제 불가 |
| **"진짜 같은 가짜" 판별류 (AI or Not 등)** | 진짜/가짜 2지선다의 중독성 검증 | 소재가 한국 아파트라는 초로컬 공감대 + 데일리 운영 |

**카피 방어 논리 (구조적 해자)**

1. **콘텐츠 운영 해자**: 게임의 재미는 "진짜 같은 가짜"의 품질에서 나온다. 이는 프롬프트 튜닝 + 검수 룰 + 편성 감각의 축적물이라 스크린샷으로 복제되지 않는다.
2. **데이터 해자**: 정답 공개 시 노출되는 실단지 메타데이터(위치·준공년도·세대수)는 K-apt 데이터 정제 파이프라인이 필요하다.
3. **선점 해자**: 데일리 게임은 "다들 하는 그 게임" 지위를 먼저 차지한 쪽이 이긴다. 카피캣은 유저의 스트릭과 인증 습관을 못 가져간다.

## 6. 단계별 범위

### 1단계 — 구현 완료 (현재)
- 게임 3종의 무한 모드: 감별 O/X, 이름 조립, 진짜 찾기. 창구 진입 즉시 시작, 횟수 제한 없음
- 제N호 공식전: 그날의 10문제, 하루 1회, 전국 정답률·상위% 집계. 게임 안 칩으로 신청하고 출전 후에는 같은 칩이 성적표가 된다
- 서버 판정(정답은 클라이언트에 내려주지 않는다)과 모드별 제한시간
- 정답 공개: 실단지는 위치·준공년도·세대수, 가짜는 "AI가 지은 이름"
- 모드별 등급 도장 + 누적 감별사 레벨, 최고 연속·콤보, 판 단위 최근 7일 백분위
- 판정 통지서 결과 화면과 접수증 공유 이미지(1080×1350 PNG)
- 구글 로그인과 비회원 모드 병행, 로그인 시 기록 클라우드 동기화
- PWA 설치(홈 화면 앱)

### 1단계 남은 것
- 출제 풀 확대(가짜 이름 추가 생성), 실단지 서울 외 지역 확장
- 일자별 출제 스냅샷과 90일 재출제 금지
- 정답 오류 제보 경로

### 2단계 — 미개설 창구
- **작명소 모드**: 브랜드·지역·펫네임 조각을 드래그로 조립해 "가장 그럴듯한 가짜 이름" 만들기. 일일 투표 + 명예의 전당. UGC로 운영 부담 없이 콘텐츠 축적.
- **우리 동네 모드**: 시/군/구 선택 시 해당 지역 단지만 출제. 당근·맘카페 등 지역 커뮤니티 확산 루트.

### 3단계 이후 (아이디어 풀, 확정 아님)
- 작명소 모드 우승작을 데일리 퀴즈 가짜 문제로 편입 (UGC → 출제 선순환)
- 테마 주간 (예: "펫네임 지옥 주간", "90년대 클래식 주간")
- 오피스텔·주상복합 확장

상세 게임 설계는 [02. 게임 상세 기획](02-game-design.md) 참조.
