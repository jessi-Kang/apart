# 02. 게임 상세 기획

## 1. 코어 루프 화면 플로우

```
[랜딩] → [문제 1/10] → (진짜/가짜 선택) → [정답 공개] → … 반복 ×10 → [결과/등급] → [공유]
```

### 1-1. 랜딩
- 오늘 날짜 + 회차 번호 ("아파트 감별사 #37 · 9월 10일")
- 시작 버튼 1개. 이미 완료한 날이면 결과 화면으로 바로 이동 + "내일 자정에 새 문제" 카운트다운.
- 첫 방문자에게만 3줄 룰 설명 오버레이 (진짜/가짜 고르기 → 10문제 → 등급). 튜토리얼 별도 없음 — 룰이 곧 튜토리얼.
- 어제 문제 다시 보기 링크 (플레이 불가, 정답 열람만 — 뒤늦게 링크 타고 온 유저의 이탈 방지).

### 1-2. 문제 화면
- 화면 정중앙에 단지명 큼직하게 한 줄 (예: "힐스테이트 리버센트럴 에듀포레"). 긴 이름은 자동 줄바꿈, 최대 2줄.
- 상단: 진행도 (●●●○○○○○○○ 3/10) + 현재 점수는 **비표시** (마지막까지 긴장 유지).
- 하단: [진짜] [가짜] 버튼 2개, 엄지 닿는 위치에 크게. 버튼 좌우 배치는 고정 (진짜=왼쪽/초록 계열, 가짜=오른쪽/보라 계열).
- 타이머 없음 — 고민하는 시간 자체가 재미. 단, 문제당 체류시간은 로깅 (난이도 보정 데이터).

### 1-3. 정답 공개 (선택 직후 같은 화면에서 전환)
- **정답/오답 피드백**: 맞히면 ✓ + 짧은 햅틱/애니메이션, 틀리면 ✗.
- **진짜였을 때**: "진짜 있는 아파트" + 메타데이터 한 줄 — `서울 서초구 반포동 · 2023년 준공 · 2,990세대`. 이 정보가 "이게 진짜라고?"라는 2차 재미와 댓글 논쟁("우리 동네 있는데요?")의 소재.
- **가짜였을 때**: "이건 AI가 지은 이름 🤖" + 생성 힌트 한 줄 (예: "실존 브랜드 + 실존하지 않는 조합"). 힌트는 가짜 이름 데이터에 미리 저장된 문구 사용.
- **전국 정답률**: "이 문제, 지금까지 41%만 맞혔어요" (실시간 집계, 표본 100명 미만이면 비표시).
- [다음 문제] 버튼으로 진행. 자동 넘김 없음 (스크린샷 찍을 시간).

### 1-4. 결과/등급 화면
- 점수 (8/10) + 등급명 + 등급 일러스트/이모지 + 오늘의 이모지 그리드.
- 오답 복기: 틀린 문제만 접힌 목록으로 (이름 + 정답 + 메타데이터). 복기가 "내일 또 해야지"의 학습 동기.
- 스트릭 표시: "🔥 6일 연속 감별 중".
- [결과 공유하기] 버튼 (핵심 CTA, 화면에서 가장 크게).

## 2. 출제 로직

| 규칙 | 내용 | 이유 |
|---|---|---|
| 전원 동일 문제 | 날짜(KST) 기반 데일리 시드. 전 유저가 같은 10문제 | "오늘 8/10" 인증이 성립하려면 문제가 같아야 함 |
| 갱신 시각 | 매일 00:00 KST | 자정 갱신 대기 문화 (Wordle 학습) |
| 하루 1회 | 완료 후 재도전 불가. localStorage + 완료 기록 | 희소성 = 습관. 비정상 재플레이는 막지 않되 집계에서 제외 |
| 진짜:가짜 비율 | 4:6 ~ 6:4 사이에서 매일 랜덤 | "항상 5:5"면 후반에 개수 세기 메타가 생김. 비율을 흔들어 매 문제를 독립 판단하게 함 |
| 난이도 커브 | 1~2번 쉬움 → 3~7번 중간 → 8~10번 어려움 2 + 중간 1 셔플 | 초반 성공 경험으로 몰입 → 후반 "이건 진짜 모르겠다"가 공유 욕구를 만듦 |
| 재출제 금지 | 동일 단지명(진짜/가짜 모두) 최소 90일 재출제 금지 | 매일 하는 유저가 문제를 외우는 것 방지 |

난이도 라벨링 기준은 [03. 데이터·콘텐츠 파이프라인](03-content-pipeline.md#3-난이도-라벨링)에서 정의.

## 3. 등급 시스템

| 점수 | 등급명 | 카드 문구 | 이모지 | 색상 톤 |
|---|---|---|---|---|
| 0~3 | **외지인** | "아파트 이름이 다 그게 그거 같죠? 정상입니다." | 🧳 | 회색 |
| 4~6 | **전세 유목민** | "발품은 팔아봤는데, 이름까진 안 외웠군요." | 🏃 | 파랑 |
| 7~8 | **부동산 카페 눈팅러** | "매일 눈팅한 짬은 못 속입니다." | 👀 | 초록 |
| 9~10 | **시어머니도 못 찾는 이름 감별사** | "당신은 이름만 봐도 평면도가 보이는 사람." | 🏆 | 금색 |

- 등급명은 자기비하+자부심이 섞인 톤 유지. "외지인"이 낮은 등급이지만 모욕이 아니라 웃긴 포지션이 되도록 문구로 보정.
- 만점(10/10) 전용 배지 별도: "완전 감별" ✨ — 그리드에 특수 테두리. 만점 인증욕이 최상위 공유 동력.

## 4. 공유 카드 포맷

### 4-1. 텍스트 공유 (클립보드 복사, 기본)
```
아파트 감별사 #37 🏢
🟩🟩⬛🟩🟩🟩⬛🟩🟩🟩 8/10
부동산 카페 눈팅러 👀
apt-gam.kr
```
- 🟩 정답 / ⬛ 오답. 문제 순서대로 — 스포일러 없이 "어디서 틀렸는지"만 드러남 (Wordle 문법 그대로 차용, 학습비용 0).
- 스레드/X/카톡 어디에 붙여도 깨지지 않는 순수 텍스트.

### 4-2. OG 이미지 (링크 미리보기 + 이미지 저장 공유)
- 결과 URL(`/r/{날짜}-{점수}-{그리드}`)마다 동적 생성: 등급명 + 점수 + 이모지 그리드 + 로고.
- 인스타 스토리용 세로형(1080×1920) 이미지 저장 버튼 별도 제공.
- 사양은 [04. 기술 사양](04-tech-spec.md#4-og-이미지) 참조.

## 5. 리텐션 장치

1. **스트릭**: 연속 참여일. 7일/30일/100일에 특수 배지. 끊기면 리셋이되, 1회 한정 "스트릭 보호"(하루 놓쳐도 유지)를 나중에 부활 장치로 검토 (MVP 제외).
2. **어제의 전국 정답률**: 랜딩에 "어제 3번 문제, 전국 23%만 맞혔어요 — [뭐였는지 보기]". 놓친 날의 FOMO를 자극.
3. **오답 복기**: 결과 화면에서 틀린 실단지의 위치·준공년도를 보여줌으로써 "다음엔 맞힌다"는 학습 루프.
4. **주간 리캡** (MVP 이후): 일요일에 "이번 주 평균 7.2/10, 상위 18%" 요약 카드.

## 6. 서브 모드 상세 (2단계)

### 6-1. 작명소 모드
"가장 그럴듯한 가짜 이름"을 유저가 직접 조립하는 UGC 모드.

- **조립 UI**: 3열 조각 팔레트에서 드래그(모바일은 탭)로 슬롯에 배치.
  - 브랜드 조각: 래미안 · 자이 · 푸르지오 · 힐스테이트 · e편한세상 · 더샵 · 아이파크 …
  - 지역/입지 조각: 한강 · 센트럴 · 리버 · 역(驛) · 파크 · 레이크 · 시티 …
  - 펫네임 조각: 포레 · 에듀 · 노블 · 퍼스티지 · 어반 · 블리스 · 그라시움 …
  - 슬롯은 2~4개 자유 조합. 조각은 매일 일부 로테이션 (매일 다른 재료 = 매일 다른 결과물).
- **제출**: 1인 1일 1작품. 제출 즉시 실존 단지명과 대조 — 실제로 있는 이름이면 "이거… 진짜 있는 아파트입니다 😱" 이스터에그 (그 자체로 공유 소재).
- **투표**: 당일 제출작 중 랜덤 2개를 보여주고 "더 진짜 같은 쪽" 고르기 (A/B 대결 방식, 목록 스크롤보다 참여 쉬움). 1인당 투표 무제한이되 같은 쌍은 다시 안 나옴.
- **명예의 전당**: 매일 자정 득표율 1위 발표. 역대 우승작 아카이브 페이지. 우승작은 제작자 닉네임과 함께 공유 카드 생성.
- **어뷰징 방지**: 투표는 세션당 기기 지문+localStorage로 중복 제한(완벽 차단보다 비용 증가가 목적), 랜덤 매칭이라 특정 작품 밀어주기 어려움, 비속어·실명·지역비하 조각은 팔레트에 아예 없음(입력창이 없는 조립식이므로 원천 차단).
- **선순환**: 우승작 풀에서 검수를 거쳐 데일리 퀴즈의 가짜 문제로 편입 → "내가 만든 이름이 오늘 문제로 나옴" 경험.

### 6-2. 우리 동네 모드
- 시/도 → 시/군/구 2단계 선택. 선택한 지역의 실단지 + 그 지역 스타일로 생성된 가짜만 출제.
- 데일리와 별개로 지역당 상시 플레이 가능 (횟수 제한 없음, 문제 풀에서 랜덤 10개). 데일리의 희소성은 지키되, 동네 모드는 "우리 동네 자랑" 확산용이므로 제한 불필요.
- 결과 카드에 지역명 명시: "강남구 감별 9/10 — 강남 토박이". 지역별 평균 점수 랭킹 ("우리 동네 평균 6.8").
- 확산 루트: 당근 동네생활·맘카페에 "OO구 사람이면 8개는 맞혀야 함" 포맷으로 시딩.
- 최소 단지 수(예: 실단지 30개) 미달 지역은 인접 지역 묶음으로 출제.

## 7. 톤 앤 매너

- **카피 톤**: 부동산 커뮤니티 밈 화법. 진지한 부동산 정보 서비스처럼 보이면 실패. 단, 특정 지역·단지·거주자를 비하하는 유머는 금지 ([05. 리스크](05-growth-and-ops.md#4-리스크-및-대응) 참조).
- **비주얼**: 텍스트(단지명)가 주인공. 아파트 일러스트는 보조. 로고·BI·조감도 등 브랜드 자산은 절대 미사용.
- **사운드**: 없음 (지하철에서 하는 게임).
