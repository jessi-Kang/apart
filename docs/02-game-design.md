# 02. 게임 상세 기획

## 1. 코어 루프 화면 플로우

```
[홈: 접수 대장] → [창구 진입 = 무한 세션 즉시 시작]
       → (문제 → 판정 → 다음) 반복 → [세션 종료] → [판정 통지서] → [공유 / 다시 도전]
                                   ↘ (선택) [제N호 공식전 10문제] → [판정 통지서]
```

> 첫 화면은 인트로가 아니라 **접수 대장 홈**이다. 전체 플로우와 계정·기록 설계는 [07. 플로우·계정·기록](07-account-and-records.md) 참조.

**본편은 무한이다.** 하루치 문제를 다 풀면 더 할 게 없는 구조는 게임을 스스로 닫는다. 창구에 들어가면 바로 세션이 시작되고, 경쟁은 누적 기록(레벨·최고 연속·콤보)과 판 단위 순위로 성립한다. 데일리 10문제는 **제N호 공식전**이라는 선택 참가 랭킹전으로 남아 있다.

### 1-1. 홈 (접수 대장)

- 순번 / 창구 / 공식전 3열 서식. 각 행이 게임 하나다.
- 창구 칸에는 그 게임의 개인 기록 꼬리표가 붙는다 ("무한 감별 · 최고 연속 12").
- 공식전 칸에는 도장이 찍힌다. 오늘 미출전이면 인주색 "공식전", 출전했으면 잉크색 "출전 완료", 미개설 창구는 점선 "미개설".
- 레벨 칩과 계정 상태 한 줄이 제목 아래에 조용히 붙는다.

### 1-2. 문제 화면 (무한)

- 상단 한 줄에 세션 상태: "무한 N번째 · 연속 X · 최고 Y". 그 오른쪽에 공식전 칩.
- 기록이 하나도 없는 사람의 **첫 문제에만** 규칙 한 줄이 뜬다. 한 번이라도 기록이 쌓이면 다시 보이지 않는다.
- 모드별 제한시간 바가 돈다. 시간이 다하면 자동 오답 제출.

| 게임 | 화면 | 제한시간 |
|---|---|---|
| 감별 O/X | 단지명 한 줄 + [진짜] [가짜] | 12초 |
| 이름 조립 | 위치·준공년도·세대수 힌트 + 조각 타일 + 정답 칸 | 40초 |
| 진짜 찾기 | 후보 4개 중 진짜 하나 고르기 | 15초 |

### 1-3. 정답 공개 (같은 화면에서 전환)

- **진짜였을 때**: "진짜 있는 아파트" + 메타데이터 한 줄 (`서울 서초구 반포동 · 2023년 준공 · 2,990세대`). 이 정보가 "이게 진짜라고?"라는 2차 재미와 댓글 논쟁의 소재다.
- **가짜였을 때**: "AI가 지은 이름" + 생성 힌트 한 줄 (가짜 데이터에 미리 저장된 문구).
- 무한에서는 연속·평균 시간·최고 기록이 한 줄로 따라붙고, 다음 문제로 넘어가거나 "여기까지"로 세션을 끝낸다.
- 자동 넘김은 없다. 스크린샷 찍을 시간을 준다.

### 1-4. 조립 전용: 초성 힌트와 속도 점수

- 15초 / 25초 / 33초가 지나면 힌트가 한 단계씩 열린다. 단계마다 **조각 하나당 무작위 위치의 한 글자**가 열리고, 열리는 자리는 시드로 고정돼 단계가 올라가도 바뀌지 않는다. 앞에서부터 몰아 열면 첫 조각이 통째로 공개돼 버리기 때문이다.
- 힌트는 **정답을 넣는 칸 안**에 표시된다. 열린 자리는 글자, 가린 자리는 점 하나. 칸 폭이 곧 그 조각의 글자 수를 알려준다.
- 공식전 점수: `max(2, 10 + round(남은초 / 4) - 힌트단계 × 4)`. 빨리 맞힐수록 높고 힌트를 본 만큼 깎인다.

### 1-5. 결과 화면 (판정 통지서)

확정 시안 `design/result3-r1-verdict.html`.

- 등급 도장이 주인공이다. 크게, 기울여 날인한다.
- 수치는 전부 순번 괘선 서식표 한 장에 접어 넣는다. 판정 그리드 / 기록 / 순위 / 감별사 등급 순.
- 무한 세션: 판정 · 세션 기록(연속·평균) · 역대 기록(신기록이면 인주색) · 판 순위(최근 7일 상위 %) · 감별사 등급.
- 공식전: 판정 · 전국 순위 · 연속 출전 · 감별사 등급. 조립은 조립 점수 행이, 진짜 찾기는 콤보 행이 추가된다.
- 검은 버튼은 화면당 하나뿐이다(공유). 나머지는 고스트 버튼.

## 2. 출제 로직

### 2-1. 무한 (본편)

| 규칙 | 내용 |
|---|---|
| 출제 | 출제 풀에서 매 문제 랜덤. 서버가 정답을 쥐고 판정한다 |
| 횟수 | 제한 없음. 세션은 사용자가 끝낼 때까지 이어진다 |
| 기록 | 연속, 최고 연속(진짜 찾기는 콤보), 평균 풀이 시간 |
| 판 순위 | 세션 종료 시 최근 7일 다른 판들과 비교한 상위 %. 표본 20판 미만이면 "집계 중" |
| 이탈 | 결과를 안 보고 떠나도(공식전 전환·로고 클릭) 그 판은 집계와 경험치에 접수된다 |

### 2-2. 제N호 공식전 (선택 참가 랭킹전)

| 규칙 | 내용 | 이유 |
|---|---|---|
| 전원 동일 문제 | 날짜(KST) 기반 데일리 시드로 10문제 생성 | "오늘 8/10" 인증이 성립하려면 문제가 같아야 함 |
| 갱신 시각 | 매일 00:00 KST | 자정 갱신 대기 문화 |
| 하루 1회 | 완주 후 재출전 불가. 같은 칩이 "성적표"로 바뀌어 결과를 다시 연다 | 희소성이 랭킹전의 전제 |
| 진짜:가짜 비율 | 4:6 ~ 6:4 사이에서 매일 랜덤 | "항상 5:5"면 후반에 개수 세기 메타가 생김 |
| 난이도 커브 | 쉬움 2 → 중간 5 → 어려움 3 | 초반 성공 경험으로 몰입, 후반의 "이건 모르겠다"가 공유 욕구를 만듦 |
| 집계 | 문제별 정답률, 점수 분포(상위 %). 표본 100명 미만이면 비표시 | |
| 재출제 금지 | **미구현.** 동일 단지명 90일 재출제 금지가 목표 | 매일 하는 유저가 문제를 외우는 것 방지 |

난이도 라벨링 기준은 [03. 데이터·콘텐츠 파이프라인](03-content-pipeline.md#3-난이도-라벨링)에서 정의.

## 3. 등급과 레벨

### 3-1. 등급 도장 (한 판의 판정)

모드마다 등급표가 따로 있다. 감별 O/X 기준:

| 점수 | 등급명 | 카드 문구 |
|---|---|---|
| 0~3 | **외지인** | "아파트 이름이 다 그게 그거 같죠? 정상입니다." |
| 4~6 | **모델하우스 구경러** | "발품은 팔아봤는데, 이름까진 안 외웠군요." |
| 7~8 | **부동산 카페 눈팅러** | "매일 눈팅한 짬은 못 속입니다." |
| 9~10 | **시어머니도 못 찾는 이름 감별사** | "이름만 봐도 평면도가 보이는 수준." |

- 이름 조립은 건설 현장 콘셉트(함정 조각 수집가 → 견습 조립공 → 현장 반장 → 설계도 없는 건축사), 진짜 찾기는 눈썰미 콘셉트(AI의 단골 손님 → 모델하우스 단골 → 공인중개사 뺨치는 눈 → 부동산 매의 눈).
- 무한 세션은 점수표 대신 세션 성적으로 도장을 찍는다(신기록 갱신 / 상급 감별 / 감별 수련 / 재수련 요망).
- **등급명 정책**: 주거 형태·주거 불안정(전세·월세·무주택 등)을 소재로 한 명칭 금지. 놀림의 대상은 항상 "아파트 작명 문화"이지 유저의 주거 상황이 아니다.

### 3-2. 감별사 레벨 (날짜를 넘는 성장축)

- 모든 게임의 정답이 경험치가 된다. 무한 정답 5점(조립은 8점), 세션 신기록 30점, 공식전은 정답 10점 + 완주 20점.
- 레벨에는 상한이 없고, 직급은 접수처 세계관을 따른다(견습 감별사 → 감별 주무관 → 주임 → 계장 → 과장 → 국장 → 수석 감별관 → 감별 명장).
- 결과 화면과 홈 칩에 노출된다. 로그인하면 기기를 넘어 이어진다.

## 4. 공유

### 4-1. 접수증 이미지 카드 (기본)

확정 시안 `design/share3-s2-receipt.html`. Canvas 2D로 1080×1350 PNG를 그린다.

- 창구에서 뽑아준 영수증 한 장이 콘셉트다. 위아래 절취 지그재그, 점선 괘선으로 나뉜 항목 열거, 판정 타일 한 줄, 등급 도장과 APPROVED, 판마다 무늬가 고정되는 시드 바코드, 붉은 주소 한 줄.
- 접수 관인은 마지막에 종이 **위에** 찍는다. 바코드를 왼쪽으로 물려 오른쪽에 도장 칸을 비워 뒀다.
- 모바일은 시스템 공유 시트, 데스크탑은 파일 다운로드로 떨어진다.
- **판정 그리드는 이모지가 아니라 그래픽으로 그린다.** 이 원칙은 화면과 카드 모두에 적용된다.

### 4-2. 공유 랜딩과 OG

- 결과 링크(`/r/{슬러그}`)는 점수·등급·판정 그리드를 통지서 서식으로 보여주고, 창구로 유도한다. 들어오면 무한이 시작된다는 것과 공식전은 게임 안에서 신청한다는 것을 한 줄로 안내한다.
- OG 미리보기 이미지는 같은 정보로 동적 생성한다. 사양은 [04. 기술 사양](04-tech-spec.md) 참조.

### 4-3. 텍스트 공유 (계획, 미구현)

```
아파트 감별사 제37호
🟩🟩⬛🟩🟩🟩⬛🟩🟩🟩 8/10
부동산 카페 눈팅러
apt-game.app
```
클립보드 텍스트는 이모지 그리드를 쓰는 유일한 자리다. 아직 붙이지 않았다.

## 5. 리텐션 장치

**구현됨**

1. **무한 세션의 장력**: 연속이 끊기는 순간이 곧 "한 판 더"의 이유다.
2. **판 순위**: 세션이 끝나면 최근 7일 다른 판들과 비교한 상위 %가 나온다. 어제의 나와 남을 동시에 이기는 축.
3. **누적 레벨과 직급**: 날짜를 넘어 쌓이는 성장. 홈에서 항상 보인다.
4. **연속 출전**: 공식전 완주로 쌓이는 스트릭.
5. **성적표 재열람**: 오늘 친 공식전 결과는 언제든 다시 열 수 있다.

**계획 (미구현)**

6. 어제의 전국 정답률을 홈에 띄우는 FOMO 장치.
7. 오답 복기 화면.
8. 주간 리캡("이번 주 평균 7.2/10, 상위 18%").
9. 스트릭 7일/30일/100일 특수 배지.

## 6. 미개설 창구 (2단계)

### 6-1. 작명소 모드
"가장 그럴듯한 가짜 이름"을 유저가 직접 조립하는 UGC 모드.

- **조립 UI**: 3열 조각 팔레트에서 드래그(모바일은 탭)로 슬롯에 배치. 브랜드 / 지역·입지 / 펫네임 조각을 2~4 슬롯에 자유 조합하고, 조각은 매일 일부 로테이션한다.
- **제출**: 1인 1일 1작품. 제출 즉시 실존 단지명과 대조해 실제로 있는 이름이면 "이거… 진짜 있는 아파트입니다" 이스터에그.
- **투표**: 당일 제출작 중 랜덤 2개를 보여주고 "더 진짜 같은 쪽" 고르기. 같은 쌍은 다시 나오지 않는다.
- **명예의 전당**: 매일 자정 득표율 1위 발표와 아카이브.
- **어뷰징 방지**: 기기 지문+localStorage로 중복 제한, 랜덤 매칭이라 밀어주기 어려움, 입력창이 없는 조립식이라 비속어·지역비하는 원천 차단.
- **선순환**: 우승작을 검수해 출제 풀의 가짜로 편입한다.

> 주의: 이미 구현된 "이름 조립" 창구는 이 모드와 다르다. 조립 창구는 실존 단지명을 복원하는 퍼즐이고, 작명소는 가짜를 만드는 UGC다.

### 6-2. 우리 동네 모드
- 시/도 → 시/군/구 2단계 선택. 선택한 지역의 실단지 + 그 지역 스타일의 가짜만 출제.
- 결과 카드에 지역명 명시("강남구 감별 9/10 — 강남 토박이"), 지역별 평균 랭킹.
- 확산 루트: 당근 동네생활·맘카페에 "OO구 사람이면 8개는 맞혀야 함" 포맷으로 시딩.
- 최소 단지 수(예: 30개) 미달 지역은 인접 지역 묶음으로 출제.
- 선행 조건: 실단지 풀이 현재 서울 한정이라 지역 확장 수집이 먼저다.

## 7. 톤 앤 매너

- **카피 톤**: 접수 창구의 공문서 화법 위에 부동산 커뮤니티 밈 감각을 얹는다. 진지한 부동산 정보 서비스처럼 보이면 실패다. 단, 특정 지역·단지·거주자를 비하하는 유머는 금지 ([05. 리스크](05-growth-and-ops.md#4-리스크-및-대응) 참조).
- **비주얼**: 텍스트(단지명)가 주인공. 도장·괘선·관인이 세계관을 만든다. 로고·BI·조감도 등 브랜드 자산은 절대 미사용.
- **사운드**: 판정 도장, 콤보, 레벨 업 등 짧은 효과음은 Web Audio로 합성한다(오디오 파일 없음).
- **배경음**: 접수 창구 앰비언스 36초 루프를 아주 낮은 볼륨(14%)으로 깐다. 기본은 켜짐이고 푸터에서 끌 수 있으며, 브라우저 정책상 첫 터치 이후에 소리가 난다. 파일은 첫 제스처 전에는 받지 않아 그냥 들렀다 나가는 사람에게는 다운로드가 발생하지 않는다.
