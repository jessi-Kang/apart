# 08. 용어집

화면에 쓰는 말을 하나로 맞춘 목록이다. 같은 것을 두 가지 이름으로 부르면
사용자는 그게 다른 것인 줄 안다. 새 화면을 만들 때는 여기 있는 말을 쓰고,
없는 개념이 생기면 먼저 이 표에 추가한 뒤에 화면에 쓴다.

## 1. 확정 용어

| 개념 | 쓰는 말 | 쓰지 않는 말 | 메모 |
|---|---|---|---|
| 게임 하나 | **창구** | 모드, 메뉴 | 홈 대장의 한 행이 창구 하나 |
| 상시 플레이 | **무한** | 무한 모드, 엔들리스 | 창구에 들어가면 바로 시작 |
| 들어와서 끝낼 때까지의 한 묶음 | **판** | 세션, 라운드, 게임 | "이번 판", "판 순위" |
| 문제 한 개 | **문제** | 라운드, 퍼즐, 문항 | 진짜 찾기도 라운드가 아니라 문제 |
| 연속으로 맞힌 수 | **연속** | 콤보, 스트릭 | 세 창구 모두 같은 말 |
| 매일 갱신되는 10문제 | **공식전** | 데일리, 본편, 미션 | "제N호 공식전" |
| 공식전에 며칠째 나왔나 | **연속 출전** | 스트릭 | |
| 맞힘 | **적중** | 정답, 히트 | 결과·공유에서 쓰는 말 |
| 한 판의 판정 | **등급** | 랭크 | 도장으로 찍힌다 |
| 쌓이는 계급 | **직급** | 레벨 등급, 감별사 등급 | Lv.N + 직급명 |
| 진행 중인 서류 | **신청서** | 접수증 | 헤더 부제 |
| 결과 서류 | **통지서** | 접수증, 성적표, 리포트 | 화면과 공유 이미지 모두 |
| 기록 모아 보는 화면 | **기록 열람실** | 마이페이지, 프로필 | |
| 남들 대비 내 위치 | **순위** (상위 N%) | 백분위, 퍼센타일 | 무한은 "판 순위", 공식전은 "전국 순위" |

## 2. 문장 규칙

- **숫자 뒤에 단위를 붙인다.** "10문제 중 7문제 적중", "최고 연속 12".
- **버튼은 짧게.** 두 어절을 넘기지 않는다. "다음 문제", "결과 보기", "통지서 공유", "창구로 돌아가기".
- **em-dash(—)를 UI 문구에 쓰지 않는다.** 가운뎃점(·)이나 줄바꿈으로 나눈다.
- **같은 정보를 두 곳에 두지 않는다.** 예를 들어 데이터 출처는 푸터에만 있고 레일에는 없다.
- **판정은 그래픽으로 그린다.** 이모지는 클립보드 텍스트 공유에만 쓴다.
- 부연은 한 곳에 한 번만. 화면이 이미 말하는 것을 설명으로 반복하지 않는다.

## 3. 세계관 어휘

접수 창구 서류를 배경으로 한다. 아래 말들이 톤을 만든다.

- 접수, 창구, 대장, 서식, 괘선, 관인, 날인, 발급, 출전, 반려
- 등급 도장 문구는 자기비하와 자부심이 섞인 톤을 유지하되, 주거 형태나
  주거 불안정을 소재로 삼지 않는다 ([02. 게임 상세 기획](02-game-design.md) 참조).
