# 아파트 감별사 (가칭)

> "이거 진짜 있는 아파트야, AI가 지어낸 거야?" — 하루 10문제 데일리 퀴즈

화면에 아파트 이름 하나가 큼직하게 뜬다. **진짜** / **가짜** 두 버튼 중 하나를 누른다. 10문제가 끝나면 등급이 나오고, 그 등급 카드를 SNS에 공유한다. 내일 또 새 문제가 나온다.

## 디자인 시안 (`design/`)

디자인 방향은 **A(접수 서류)** 로 확정. 모든 시안은 모바일 퍼스트 반응형(768px/1024px) 인터랙티브 목업이다.

| 파일 | 상태 |
|---|---|
| `sian-a-document.html` | **확정.** 접수 창구 홈 + 감별 O/X + 이름 조립 + 진짜 찾기 + 접수 대장 |
| `sian-c-gameshow.html` | 대안 보관(구 확정안, 게임쇼 팝) |
| `submodes-a.html` · `submodes-c.html` | 서브 모드(작명소·우리 동네) 시안 |
| `sian-b-nightboard.html` | 디벨롭 중단 |
| `sharecard-*.html` | 이미지 공유 카드 1차안. 보류(재작업 예정) |

## 개발 (`web/`)

M1 개발 진행 중. Next.js 15 + TypeScript, 확정 디자인 A 적용.

```bash
cd web
npm install
npm run dev        # http://localhost:3000
```

현재 구현: 본편 감별 O/X 코어 루프 (데일리 시드 출제 → 서버 판정 → 등급/공유 → 스트릭·전국 정답률 집계).

## 현재 단계

**M1 개발** — 범위는 [로드맵](docs/05-growth-and-ops.md#5-로드맵) 참조. 디자인 파일 수정 시 impeccable 검증이 필수다(`CLAUDE.md` 참조).

## 핵심 설계 원칙 (요약)

1. **하루 한 번, 전원 동일 문제** — Wordle식 습관 루프와 "오늘 8/10" 인증 문화를 만든다.
2. **가짜 이름 품질이 게임의 전부** — LLM 프롬프트 튜닝과 검수에 리소스를 가장 많이 쓴다.
3. **런타임 AI 호출 0** — 가짜 이름은 사전 배치 생성·캐싱. 서버비 거의 0으로 시작.
4. **콘텐츠 운영이 해자** — 문제가 매일 바뀌므로 UI를 카피해도 운영을 못 따라온다.
5. **로고는 절대 쓰지 않는다** — 브랜드명은 사실 정보로만 텍스트 사용. 지역 비하성 가짜 이름은 검수에서 걸러낸다.
