# 아파트 감별사 QA

## 왜 이 스킬이 있나

이 프로젝트에서 사람이 반복해서 같은 종류의 결함을 잡아 줬다. 그때마다 그 자리만
고치고 넘어가니 다음 변경에서 되살아났다. 되살아나는 것을 기계가 먼저 잡게 한다.

**가장 중요한 규칙: 마커가 아니라 동작을 확인한다.**
"코드에 그 문자열이 있다"는 통과가 아니다. 화면을 열어 재고, API를 찔러 보고,
라이브 응답을 받아 본 것만 통과다. 이 원칙을 어겨서 "고쳤다"고 잘못 보고한 적이 있다.

## 실행

```bash
cd web && npm run build && DATABASE_URL= npm start &   # 반드시 DB를 떼고 띄운다
node .claude/skills/qa/scripts/qa.mjs [all|layout|behavior|copy|data|live]
```

`DATABASE_URL=`를 비우는 이유: `web/.env.local`에 운영 연결 문자열이 있어서
그냥 띄우면 **점검용 쓰기가 운영 집계에 섞인다.** 실제로 한 번 섞여서 지웠다.

전역 playwright를 빌려 쓴다(의존성을 늘리지 않는다). 없으면 레이아웃·동작 검사는
건너뛰고 그 사실을 보고한다 — 조용히 통과시키지 않는다.

## 점검 항목과 그 항목이 생긴 이유

### 1. 레이아웃 (`layout`)
`web/scripts/check-layout.mjs`를 390·480·768·1024px × 화면 6종으로 돌린다.

| 검사 | 왜 |
|---|---|
| **덜 찬 문단** — 여러 줄인데 가장 긴 줄이 칸 폭의 80%(좁은 칸 74%) 미만 | "오른쪽 여백이 남는데 꽉 안 찬다"는 지적을 세 번 받았다. 범인은 `text-wrap: balance`(줄을 고르게 맞추려 모두 짧게)와 `pretty`(짧은 마지막 줄을 막으려 앞 줄에서 단어를 끌어내림)였다. 같은 문단 실측: auto 88% / pretty 67% / balance 57% |
| **심한 고아 줄** — 마지막 줄이 가장 긴 줄의 20% 미만 | 끝이 뚝 잘린 모양. 다만 짧은 마지막 줄 자체는 흐르는 글의 정상이라 20%까지만 본다 |
| **세로 치우침** — 상자 안에서 글자가 위아래로 6px 넘게 쏠림 | 격자에서 버튼이 형제만큼 늘어나는데 `display:block`이면 글자가 위에 붙는다("창구로 돌아가기") |

**고치는 법**: `text-wrap`을 떼거나 **문구를 줄인다.** `<br>`로 손수 끊지 말 것 —
폭이 바뀌면 그 자리에서 그대로 꺾여 더 나빠진다. 본문에 `text-wrap`을 다시 붙이지 말 것.
`balance`는 가운데 정렬된 제목·단지명처럼 줄이 고른 것이 곧 모양인 곳에만.

### 2. 동작 (`behavior`)
| 검사 | 왜 |
|---|---|
| PWA 설치 가능 (`Page.getInstallabilityErrors` 빈 배열) | 매니페스트 링크가 body로 스트리밍돼 설치가 막힌 적 있다 |
| 배경음이 실제로 울리는가 (AudioContext gain 계측) | "배경음 들어갔어?"를 마커로 답하면 안 된다 |
| 공유 이미지 파일명이 ASCII인가 | 한글 파일명은 크롬이 `download` 속성을 버려 확장자 없는 파일로 떨어진다 |
| 구역 격리 — `?area=`로 뽑은 문제에 다른 지역 실단지가 섞이는가 | 지역 토큰 키가 시군구 이름뿐이라 서울 중구와 부산 중구가 충돌한 적 있다 |
| 구역별 공식전 — 같은 구역 두 번 호출이 같은 문제인가, 모르는 구역이 전국으로 떨어지는가 | 순위가 성립하려면 같은 구역 참가자가 같은 문제를 풀어야 한다 |
| 창구별 집계 분리 | 세 창구가 한 칸을 써서 조립 1번과 감별 1번 정답률이 합산된 적 있다 |

### 3. 일관성 (`copy`)
| 검사 | 왜 |
|---|---|
| 화면 문구가 코드와 어긋나는가 | 공식전을 구역별로 바꿔 놓고 "전국 공통입니다" 안내를 안 지운 적 있다. **동작을 바꾸면 그 동작을 설명하는 문구부터 grep한다** |
| 용어집(`docs/08-glossary.md`) 위반 — 세션·라운드·콤보 등 | 같은 것을 두 이름으로 부르면 사용자는 다른 것인 줄 안다 |
| UI 문구의 em-dash | 프로젝트 금지 규칙 |
| `:hover`가 `@media (hover: hover)` 밖에 있는가 | 터치에서 탭 뒤에도 남아 "누른 것이 계속 붉게" 보인다 |
| `ch` 단위 폭 제한 | `ch`는 숫자 0의 폭이라 한글은 의도한 글자 수의 절반에서 꺾인다 |
| 이모지 사용 (클립보드 공유 텍스트 외) | 판정·그리드는 SVG로 그린다 |
| **나가는 문이 둘인가** — 머리글 X와 "창구로 돌아가기"가 한 화면에 | 같은 일을 하는 문이 둘이면 어느 쪽이 무엇인지 잠깐 생각하게 된다. 게임 화면에서 한 번 고쳤는데 새로 만든 화면 넷에 똑같이 둘 다 넣었다. 사람이 눈으로 잡던 항목을 검사로 옮긴 이유 |

### 4. 데이터 (`data`)
- `npm run validate-pool` — 가짜가 실단지와 사실상 겹치면 실패. **실단지를 늘릴 때마다 겹치는 가짜가 새로 생긴다**(확장 때마다 3~7건씩 걸렸다).
- 관리 단위 행(`201동`·`제2관리사무소`·`임대`)이 출제 풀에 남아 있는가.
- 구역별 출제 풀 두께 — 시·도별 실단지·조립 퍼즐 수가 문턱(20) 위인가.

### 5. 배포 (`live`)
- 방금 푸시한 내용이 apt-game.app에 반영됐는가 (번들에서 확인, 마커 아님).
- 옛 주소(`apt-gam-jessikang.vercel.app`)가 정식 도메인으로 308 넘기는가 — 안 넘기면
  그 주소로 설치한 앱의 로그인이 `redirect_uri_mismatch`로 막힌다.
- 구글 OAuth redirect_uri가 등록된 값과 일치하는가.

## 보고 방식

- 통과한 것은 한 줄로, **실패한 것은 무엇이 왜 어긋났는지 수치와 함께** 쓴다.
- 자동으로 못 보는 것은 "확인 못 함"으로 남긴다. 통과로 묶지 않는다.
- 링크를 줄 때는 먼저 열어 보고 동작하는 것만 준다.

  "완료"로 읽힌다
- 눌리는 자리에 눌린다는 표시가 있는가
