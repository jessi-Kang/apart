# 주간 점검 리포트

`.github/workflows/weekly-balance.yml`이 매주 월요일 08:47(KST)에 `web/scripts/weekly-balance.mts`를 돌려
`날짜.md`로 여기에 쌓는다. 같은 내용은 이슈 `야간 작업 일지`에도 댓글로 남는다.

세 창구가 "읽지 않고는 못 맞히는" 게임인지 본다.

1. 실제로 나간 문제: 창구별 최근 7일 정답률, 감별 이름별 진짜·가짜 비율과 속은 비율(지난 점검 이후)
2. 출제 규칙: 감별 진짜 비율·최장 연속, 구역별 가짜 되풀이
3. 감별 겉모양: 띄어쓰기·글자 수·끝 낱말로 찍을 수 있는가
4. 진짜 찾기: 넷 중 겉모양으로 고르는 수법의 적중률(찍기 25%)
5. 이름 조립: 미끼 조각이 정답 조각과 모양으로 구별되는가

손으로 돌릴 때: `cd web && npm run weekly-balance` (결과는 `/tmp/balance.md`). `DATABASE_URL`이 없으면 1번을 건너뛴다.
